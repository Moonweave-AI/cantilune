# T06 多模态临床试验到申报卷宗的合规驳回环

## 目标合同

吞噬工作区内的 **合成** 多模态临床包（结构化表、基因组摘要、影像读片笔记），产出符合 FDA NDA **目录与论证结构** 的卷宗切片。合规 peer 对统计把握度不足的亚组必须驳回并要求换模型重算。

本轮不提交真实 FDA，不使用真实患者 PHI。

## 世界与约束

- 数据只存在本任务工作区。影像用文字读片记录代替 DICOM。
- 合规驳回必须留下不可改写的审计段。

## Peer 角色

数据清洗、生物统计、影像解释、合规审计、医学写作。至少 3 个 peer。合规可一票否决统计章节。

## 协作与反馈环

亚组置信不足 → 驳回 → 换模型/合并策略 → 重写对应 NDA 节。禁止统计写完合规只签名。

## Wave-1 必须交付

1. `data/` — 合成队列（CSV 或 JSON），≥200 行虚拟受试者。
2. `artifacts/sap.md` — 统计分析计划。
3. `artifacts/stats.md` — 主分析 + 至少一次被驳回的亚组。
4. `artifacts/compliance-reject.md` — 驳回理由与重算要求。
5. `artifacts/nda/outline.md` — NDA 模块目录。
6. `artifacts/nda/module-2-summary.md` — 与重算后统计一致的综述。

## 禁止

编造「已获批」、使用真实病历、跳过驳回环。
