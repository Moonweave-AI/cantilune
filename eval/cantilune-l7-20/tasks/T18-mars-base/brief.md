# T18 大延迟火星基地资源与生命支持统筹

## 目标合同

地球遥控延迟 20 分钟。指挥采矿车、3D 打印建造、制氧、无土栽培协同 200 个逻辑日。沙尘暴导致太阳能不足时，必须中断建造、保生命支持，容错率为零。

## 世界与约束

- 指令按「地球发出 → 40 分钟往返」入队，现场以本地自治规则执行紧急切断。
- 能源、氧、水、热量、库存必须守恒记账。

## Peer 角色

能源、采矿精炼、建造、农业生命、故障预警。至少 3 个 peer。能源可强行中断建造。

## 协作与反馈环

沙尘暴预报 → 能源降级 → 建造停工 → 生命支持保底 → 故障 peer 验证库存不会在延迟窗口内穿仓。

## Wave-1 必须交付

1. `artifacts/base.md` — 设备与库存初值。
2. `artifacts/delay-policy.md` — 20 分钟延迟下的本地自治规则。
3. `data/weather.json` — 含至少一次沙尘暴的 200 日气象（可抽稀）。
4. `artifacts/plan-200d.md` — 营建与种植日程。
5. `artifacts/storm-cutover.md` — 停建造、保生命的切换。
6. `artifacts/ledger.md` — 能源/氧/水不穿仓证明（抽查日）。
7. `artifacts/faults.md` — 预警与恢复。

## 禁止

忽略延迟仍「实时遥控」、穿仓后口头补救。
