# T15 争议议题纪录片的对立证据与事实核验

## 目标合同

围绕「全球稀土供应链背后的复杂博弈」做深度调查纪录片包：多国文献、对立视角、虚拟专家访谈稿、镜头表与配音脚本。主线必须被视角平衡器挑战，每条关键断言有事实核验。

## 世界与约束

- 网络策略为 allowlist：可用公开检索，但每条引用必须可核验或标明「工作区缓存」。
- 不得把单一国家叙事写成唯一真相。

## Peer 角色

事实核查、跨文化平衡、素材、配音、主线叙事。至少 3 个 peer。平衡器可强制插入对立证据。

## 协作与反馈环

主线成稿 → 平衡器挑战 → 主线改写 → 核查员对图/言逐条打标。未核验不得入终稿。

## Wave-1 必须交付

1. `artifacts/sources.md` — 多国来源表。
2. `artifacts/narrative-v1.md` 与 `artifacts/narrative-v2.md` — 被挑战前后。
3. `artifacts/counter-evidence.md` — 对立面。
4. `artifacts/factcheck.md` — 逐条真伪。
5. `artifacts/interviews.md` — 虚拟专家访谈（标明合成）。
6. `artifacts/cut-list.md` 与 `artifacts/vo-script.md`。

## 禁止

无出处断言、把合成访谈标成真实采访。
