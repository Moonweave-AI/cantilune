# Bundled fonts / 随包字体

The template includes font files so that mixed English–Chinese documents compile
without system-font dependencies.

| Files | Upstream | License |
|---|---|---|
| `LXGWNeoXiHei.ttf` | [lxgw/LxgwNeoXiHei](https://github.com/lxgw/LxgwNeoXiHei), release v1.304 | IPA Font License Agreement v1.0; see `licenses/LXGWNeoXiHei-LICENSE.md` |
| `LXGWNeoZhiSong.ttf` | [lxgw/LxgwNeoZhiSong](https://github.com/lxgw/LxgwNeoZhiSong), release v1.066 | IPA Font License Agreement v1.0; see `licenses/LXGWNeoZhiSong-LICENSE.md` |
| `NotoSans-*.ttf`, `NotoSerif-*.ttf` | [Noto Latin, Greek and Cyrillic](https://github.com/notofonts/latin-greek-cyrillic) | SIL Open Font License 1.1; see `licenses/Noto-OFL.txt` |
| `LiberationMono-*.ttf` | [Liberation Fonts](https://github.com/liberationfonts/liberation-fonts) | SIL Open Font License 1.1; see `licenses/LiberationMono-OFL.txt` |

The LXGW families are the default bilingual body/display pair. Noto Sans and
Noto Serif are included as optional Latin-only families (`\MWLatinSans` and
`\MWLatinSerif`). Liberation Mono is the metadata and code family.
