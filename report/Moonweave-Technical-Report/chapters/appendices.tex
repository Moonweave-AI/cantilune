\section{Verification interpretation / 验证含义}

The ordinary build reconstructs the pinned Lean project. The provenance-aware gate checks source
integrity and binds a proof status to the manifest and durable evidence. Neither command provides
an independent review. A future reviewer should validate both the mechanical evidence and the
scope statement attached to each central theorem \citep{cantiluneFormalReadme,cantiluneManifest}.
