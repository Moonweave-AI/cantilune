\section{Theory promotion path / 理论推进路径}

The next path is a review and conformance sequence, not a canary deployment. The current branch
binds generic source and build evidence; subsequent gates test whether that record withstands
independent scrutiny and whether a concrete package can instantiate the declared interfaces.

\section{Change triggers / 变更触发条件}

{\raggedright
The evidence record should be re-evaluated when any of the following changes: the verified source
commit, Lean or mathlib lock, proof manifest, evidence hash, central theorem scope, reviewer
assignment, FCP/ADR status, or a product's declared operational rule family. A documentation-only
change may preserve the existing proof identity, but it must not silently rewrite the status or
scope communicated to readers.\par}

\begin{MWCallout}[MWAmber]{No rollback protocol is claimed}
There is no deployed Cantilune runtime to promote or roll back. The reversible operation here is a
claim: if a source/evidence binding or review conclusion becomes invalid, the report must return
to the narrower status rather than retaining an obsolete “proved” or “ready” summary.
\end{MWCallout}
