# 有限 DPOI–预层桥：已证片段与停止边界

状态：实现/评审证据；并非 QA-L4 批准
日期：2026-07-23
风险 / 质量 / 成熟度：S2 / QA-L4 目标 / Pre-FCP-M1
决策授权：RFC-0002 与 ADR-0001

> **历史范围说明：** 本文件记录了首个固定宿主的薄包含（thin
> inclusion）/`InterfaceLocal` 桥。研究日志 0005 与 0006 以任意单态
> （monic）预层粘合/补/并发、有限位置补/结果/剩余闭包，以及将全局单射具体匹配
> 发送到类型化切片单态的函子式主动支撑归一化，取代了该限制。它们并未证明
> 整体切片等价或无条件内蕴 M-粘性定理。

## 已实现定理表面

`formal/Cantilune/Core/FinitePresheafDPOI.lean` 构造了：

- 一个六排序关联（incidence）范畴与类型化预层切片；
- 一个经认证类型化开放超图的有限主动支撑视图；
- 这些视图之间的薄包含范畴；
- 一个从该固定宿主包含范畴到切片中的忠实函子；
- `Type` 中的逐分量交/并 pushout；
- 它们到关联预层的逐点提升及向类型化切片的反射；
- 为每个可执行包含事件提供的一个上下文恒等匹配 DPO 见证；以及
- 为每个满足 `InterfaceLocal` 的事件提供的一个选定的
  `L ← K → R` 规则与两个真正的、一般非恒等的 DPO pushout 方块。

可执行补在 `DPOI.AdmissibleRewrite` 中于识别、悬挂与边界条件下由有限删除构造。
对于固定的可执行支撑，它作为经认证图是相等唯一的；该相等给出其编码整体视图的
同构。粘性仅在 pushout 方块构造完成后使用。它并未被用作 pushout 补的存在定理。

针对核心文件与 `Cantilune.Tests.FinitePresheafDPOI` 的定向局部验证成功。代码树
仍未提交，故此证据不提升任何中心义务。

## 独立评审结果

一次独立只读 Agent 评审接受了该范围化定理：

> 对于固定的经认证宿主，有限主动支撑视图与包含态射忠实嵌入到固定的类型化
> 预层切片中。交/并支撑方块在其中是 pushout。一个
> `InterfaceLocal` 可执行包含事件产生两个 DPO 方块。

评审以四条独立理由拒绝了每一个更强的泛等价主张。

1. 具体源/目标关联载体保留 `Fin` 端口位置，但类型图仅记录
   `(generator, object type)`。同一类型的重复端口因此可被环境切片态射置换。
2. `encodingFunctor` 的源是单个固定宿主的薄视图范畴，而非所有类型化开放超图
   与一般保结构态射的范畴。其忠实性并未确立满性、对象反射、本质像或等价。
3. `Contextual.derivation` 是一个合法但退化的包装，规则为
   `G ← D → H` 且匹配恒等。它未刻画与宿主无关的规则或合法匹配。
4. `Local.derivation` 仅对选定的包含事件加 `InterfaceLocal` 证明补存在。
   没有关于任意单态匹配的定理，也没有范畴并发/临界对定理。

## 剩余证明义务

在 CENTRAL-02/CENTRAL-03 或 T2 可被提升之前，理论仍需要：

- 一个位置类型图，例如依赖端口类型
  `Σ g, Fin (input g).length` 与 `Σ g, Fin (output g).length`；
- 预期的类型化开放超图、边界与保序关联态射的范畴；
- 一个连接该范畴与适当切片子范畴的满/忠实或本质像刻画；
- 一个关于任意单态匹配的显式 `LegalMatch` 谓词；
- 在选定粘合/应用条件成立时补存在，加上至相容同构唯一的唯一性；
- 顺序推导、独立性条件、复合规则、结果同构，以及范畴并发定理；以及
- 从这些推导到预期 DAG 与 Petri 投影规则映射的连接。

因此，`dpo_result_unique` 与 `dpo_concurrency` 仍为
`partial_scaffold`；RFC-0002 仍为 Draft，ADR-0001 仍为 Proposed，且
QA-L4 人工评审仍待进行。
